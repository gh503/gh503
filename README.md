## 现在在做

### [Quench3D](https://github.com/gh503/quench3d) · 纯 Rust 的 3D 引擎

自带从零实现的物理引擎（宽相 / 窄相、顺序冲量求解器、5 种关节、角色控制器），渲染基于 `wgpu`，
桌面端 / Web / CLI / MCP 共用一套代码，约 3.7 万行 Rust + 0.65 千行 WGSL，引擎本体 `#![forbid(unsafe_code)]`。

`Rust` `wgpu` `WASM` `物理仿真` — [在线 Demo](https://gh503.github.io/quench3d/) · [源码](https://github.com/gh503/quench3d)

### [modkit M1](https://github.com/gh503/robot-modkit) · 可拆装的模块化机器人

差速底盘 + 4 自由度机械臂 + 夹爪：参数化 CAD、可测固件、Python 上位机、浏览器实时 3D 查看器。
目标不是拍演示视频，而是能独立完成一件物理任务——导航 → 识别 → 抓取 → 放置。

`Python` `C++` `CAD` `机器人` — [在线 3D 查看器](https://gh503.github.io/robot-modkit/) · [源码](https://github.com/gh503/robot-modkit)
